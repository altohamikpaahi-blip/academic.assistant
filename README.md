# المساعد الدراسي الجامعي

تطبيق أندرويد (React + Capacitor) لمراجعة المقررات: رفع محاضرات، شات بيجاوب من محتواها، وتوليد امتحانات — كل ده **محلي بالكامل على الجهاز وبدون أي API خارجي أو إنترنت**.

## هيكل المشروع

```
├── src/                      كود التطبيق (React + TypeScript)
│   ├── screens/               الشاشات (دخول، مقررات، مراجعة، لوحة تحكم)
│   ├── screens/tabs/           التبويبات التلاتة (محاضرات، شات، امتحان)
│   ├── lib/                   استخراج نصوص، بحث، توليد أسئلة، تنبيهات، تخزين
│   └── data/courses.ts         قائمة السمسترات والمقررات - عدّلها بمقررات كليتك
├── android-overrides/         ملفات أندرويد المخصصة (شرح تحت)
├── .github/workflows/         بناء الـ APK تلقائياً على GitHub
├── capacitor.config.ts        إعداد Capacitor
└── index.html
```

## إيه اللي اتعدل من الملفات اللي رفعتها

| الملف | القرار | السبب |
|---|---|---|
| `MainActivity.java` | **بدون تعديل** | كان صحيح تماماً |
| `strings.xml` | **بدون تعديل** | كان كامل وصحيح |
| `AndroidManifest.xml` | **اتعدل** | ضفت صلاحيات التنبيهات (`POST_NOTIFICATIONS`, `SCHEDULE_EXACT_ALARM`) اللازمة لتذكيرات المذاكرة، وحدّدت حد أقصى للـ storage permissions القديمة (`maxSdkVersion="32"`) عشان تتوافق مع أندرويد 13+. **حذفت** `RECORD_AUDIO` لأنها مش مستخدمة في أي ميزة بالتطبيق — لو محتاجها لميزة صوتية مستقبلية قولّي أرجعها. |
| `index.html` | **بدون تعديل** | استخدمته زي ما هو |
| `index.css` | **اتعدل بالإضافة** | ضفت شوية أنماط أساسية بسيطة فوق `@import "tailwindcss"` |

ملفات جديدة ضرورية كنت ناقصها بالكامل: كل مجلد `src/`, `package.json`, `vite.config.ts`, `tsconfig.json`, `capacitor.config.ts`, `.github/workflows/build-apk.yml`, و`android-overrides/file_paths.xml` (كان الـ Manifest بيشاور عليه بس مش موجود).

## ملحوظة مهمة عن مجلد android/

**متبعتش مجلد `android/` نفسه في المشروع (موجود في `.gitignore`).** ده مقصود:
مشروع الأندرويد الأصلي (ملفات Gradle، الـ wrapper، الأيقونات) معقّد جداً إنه يتكتب يدوي بشكل موثوق، فبدل كده الـ workflow بتاع GitHub Actions بيخلي أداة Capacitor الرسمية تولّده تلقائياً كل مرة (`npx cap add android`)، وبعدين بينسخ فوقه الملفات المخصصة اللي في `android-overrides/` (المانيفست، الـ MainActivity، الخ). الطريقة دي أضمن وأقل عرضة للأخطاء من كتابة ملفات Gradle يدوياً.

## إزاي تنشره على GitHub وتبني الـ APK من هناك

1. اعمل repository جديد على GitHub وارفع المشروع كامل (بكل الملفات اللي هنا).
2. من تبويب **Actions** في الـ repo، الـ workflow `Build Android APK` هيشتغل تلقائياً مع أي `push` على `main`. تقدر كمان تشغّله يدوي من تبويب Actions → Run workflow.
3. لما يخلص (بياخد كذا دقيقة)، هتلاقي ملف الـ APK جاهز في تبويب Actions → اضغط على آخر run → هتلاقيه تحت **Artifacts** باسم `academic-assistant-debug-apk`.
4. حمّل الملف، فكّه (zip)، وهتلاقي جواه ملف `.apk` تقدر تنزّله على أي موبايل أندرويد مباشرة.

**تعديل الكود على GitHub مباشرة:** أيوه ممكن — تفتح أي ملف من `src/` على موقع GitHub، تعدّله (زرار القلم), تعمل commit، والـ workflow هيشتغل لوحده ويبني نسخة APK جديدة أوتوماتيك. مش محتاج تنزّل حاجة على جهازك.

## قبل ما ترفع، عدّل المقررات

افتح `src/data/courses.ts` وحط أسماء مقررات كليتك الحقيقية بدل البيانات التجريبية.

## حدود مهمة (لازم تعرفها)

بما إن مفيش API ذكاء اصطناعي خارجي، الشات والامتحان شغالين بنظام **بحث واستخراج من النصوص** مش فهم لغوي حقيقي:
- الشات بيدور على أقرب جمل في المحاضرات المرفوعة لكلمات سؤالك ويرجعهالك — مش هيقدر "يستنتج" إجابة مش موجودة حرفياً في النص.
- الامتحان بيتولّد بقوالب جاهزة (حذف كلمة من جملة، تبديل كلمة لعمل عبارة خاطئة) من نفس النصوص.
- لازم الملفات المرفوعة تكون فيها نص حقيقي (مش صور ممسوحة ضوئياً / سكانات) عشان الاستخراج يشتغل صح.
